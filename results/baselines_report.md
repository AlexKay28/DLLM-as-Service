## 4. Verdict

1. **Structural fields:** Drain-only achieves 0.833 Field-F1 vs FlowFill's 0.907 — a gap of 0.074. The gap is **entirely from semantic fields** (event_type, affected_entity, remediation_hint) which Drain cannot produce.

2. **Hybrid estimate:** A Drain + small-LLM hybrid would achieve ~0.865 Field-F1 (vs FlowFill's 0.907) at ~50768 ev/s (vs 4350 ev/s). The F1 gap is 0.042 — small enough to challenge the paper's end-to-end diffusion claim.

3. **Anomaly detection:** Both baselines achieve 1.000 Anomaly-F1 (using native BGL labels), vs FlowFill's 0.865. Classical methods **match FlowFill** on anomaly detection — the LLM adds no value here when native labels exist.

4. **Perturbation robustness:** Rule-based collapses to 0.426 F1 under mixed perturbation (intensity=1.0). Drain-only degrades to 0.623. This is where end-to-end LLM approaches have a genuine advantage.

5. **Bottom line:** A hybrid approach would be faster and nearly as accurate on clean data, but **less robust to perturbation and drift**. The paper's value proposition holds for adversarial/evolving log environments, but is weaker than claimed for stable production logs where classical methods already work well.
